# 分店週報儀表板

透過 Ragic API 自動彙整各分店每週營運狀況的儀表板網站。

## 功能

- 自訂日期篩選（本週 / 上週 / 本月 / 上個月 / 自訂）
- 總覽頁：KPI 指標、每日趨勢、分店佔比圓餅圖、各分店概覽表
- 分店比較：橫向排行 + 詳細數據比較
- 主管日誌：各分店值班記錄（交接、客訴、其他事件）
- 設定頁：API Token、表單路徑、欄位對應（儲存在瀏覽器）

## 部署到 Vercel（3 步驟）

### 方法 A：直接上傳資料夾

1. 前往 [vercel.com](https://vercel.com) 並登入
2. 點擊 **Add New Project**
3. 選擇 **Upload** → 上傳此資料夾
4. 點擊 **Deploy** 即完成 ✓

### 方法 B：透過 GitHub

1. 將此資料夾推送到 GitHub repo
2. 在 Vercel 選擇 **Import Git Repository**
3. 選擇你的 repo，點擊 **Deploy**

## 初次使用設定

部署完成後：

1. 進入網站，點擊左側 **設定**
2. 填入 **Ragic API Token**（Base64 格式）
3. 填入 **Ragic 表單路徑**，例如：`yohannam/ragicsales-order-management/11`
4. 按下 **儲存設定**
5. 回到總覽，選擇日期區間，點擊 **載入報表**

## 欄位對應

預設對應以下 Ragic 欄位名稱：

| 欄位 | 預設值 |
|------|--------|
| 營業日期 | 營業日期 |
| 分店名稱 | 分店簡稱 |
| 當日營業額 | 當日營業額 |
| 用餐人數 | 用餐人數 |
| 用餐組數 | 用餐組數 |
| No Show | No Show組數 |
| 客單價 | 客單價 |
| 值班人員 | 值班人員 |
| 交接事項 | 佈達/交接事項 |
| 客訴 | 當日客訴與事件處理 |
| 其他事件 | 當日其他事件分享 |

如欄位名稱不同，可在設定頁的「欄位對應」自行修改。
